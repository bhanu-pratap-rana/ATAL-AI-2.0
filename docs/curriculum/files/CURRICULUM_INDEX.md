## 📊 Curriculum Structure

### Level 1 (Basic) - Foundation Stage
- **Target:** Students with minimal digital exposure
- **Topics:** Computer fundamentals, OS basics, Internet fundamentals, Digital communication, Contextual applications
- **Duration:** 20-30 hours
- **Assessment:** 500 points total (100 per module)

### Level 2 (Intermediate) - Skill Building Stage
- **Target:** Students who completed Basic level
- **Topics:** Office productivity, Multimedia creation, Web technologies, Digital marketing, Cyber security
- **Assessment:** Project-based + continuous assessment

### Level 3 (Advanced) - Mastery Stage
- **Target:** Students who completed Intermediate level
- **Topics:** Programming, AI/ML, Data analysis, Web development, Digital entrepreneurship
- **Assessment:** Advanced projects + portfolios

## 🔧 Technical Details

### Assessment Policy (Uniform 70% Rule)
All segment pass thresholds use **70% (rounded up)** for clarity and fairness:
- Practical 20 pts → Pass ≥14/20
- MCQ 25 pts → Pass ≥18/25
- Reflection 15 pts → Pass ≥11/15
- **Overall module pass:** ≥70/100 with all segment thresholds met

### Cultural Integration
- **Language:** English with Assamese/Hindi support
- **Context:** Northeast India rural communities
- **Examples:** Local crafts (Muga silk), festivals (Bihu), geography (Brahmaputra)
- **Focus:** Community development, cultural preservation
