## Bugs / UX Findings

### B1 — DataModal does not close on `Escape` key
- **Repro:** Open any metric drill-in modal. Press `Escape`. Modal remains open.
- **Workaround:** Click `[aria-label="Close modal"]` (X icon) or the "Close" button at the bottom.
- **Impact:** a11y / keyboard-only users.
- **Fix:** Add `useEffect` keydown listener for `Escape` in the `DataModal` component ([`apps/web/src/components/admin/DashboardMetrics.tsx:395`](../../../apps/web/src/components/admin/DashboardMetrics.tsx#L395) — confirm whether the underlying `DataModal` already supports `onEscape`).

### B2 — PeriodicSync permission warning leaks to dev console
- **Repro:** Any page in dev mode produces `[WARN] [PeriodicSync] Permission not granted {state: denied}` from the registered service worker.
- **Severity:** Cosmetic. Not user-visible.
- **Fix:** Guard the `registration.periodicSync.register(...)` call with `if ((await navigator.permissions.query({ name: 'periodic-background-sync' })).state === 'granted')` before invoking, or suppress the warning in dev.
